## Semantic Versioning

Format: MAJOR.MINOR.PATCH  
Example: 2.1.3

- MAJOR → Breaking changes (1.0.0 → 2.0.0)  
- MINOR → New features (1.0.0 → 1.1.0)  
- PATCH → Bug fixes / small improvements (1.0.0 → 1.0.1)

## Responsive Design Testing

The website was tested on different screen sizes using browser developer tools.

### Desktop View
The website displays a multi-column layout with full navigation visibility.

### Tablet View
The navigation adapts to smaller screens and content spacing is reduced for improved readability.

### Mobile View
The layout changes to a single-column design. Product cards stack vertically and images scale automatically to fit smaller screens.

### Screenshots
Screenshots of desktop, tablet, and mobile views have been included in the screenshots folder within the repository.
